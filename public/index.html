    How TodCode works, and where the open-source AI sits

    You give TodCode code. The browser sends it to our own small server, which adds a strict prompt and asks an open-weight language model to explain it. The answer comes back as Markdown and is cleaned before it is shown.

    browser  →  POST /api/explain  →  Node server (holds the key)
                                     ├─ Groq: qwen/qwen3.8-27b
                                     └─ Ollama on your laptop (no cloud at all)

    The model is the product. Without it there is nothing to show: no rules engine, no templates. We use open weights because the same code runs against a hosted model today and a model on your own machine tomorrow, by changing three environment variables. Your code never has to leave your computer.
